# Enciclopédia Lionel Messi — The Messi Chronicles

Portal digital premium dedicado à carreira de **Lionel Messi**: história, estatísticas atualizadas, títulos, gols icônicos, galeria e momentos marcantes.

---

## 🌟 Destaques do Projeto

- **Estatísticas Atualizadas**: Registros completos de gols, assistências e títulos por clube e Seleção Argentina.
- **Linha do Tempo Interativa**: A jornada desde a infância em Rosário até as conquistas recentes no Inter Miami e Copa do Mundo.
- **Coleção de Gols**: Lances marcantes com categorização por clube, torneio e vídeos integrados.
- **Galeria e Vídeos**: Acervo visual e momentos históricos da carreira do camisa 10.
- **Design Imersivo**: Tema dark com acentos dourados, micro-animações, glassmorphism e alta performance.

---

## 🚀 Tecnologias Utilizadas

- **Framework**: [React 19](https://react.dev/) + [TanStack Start](https://tanstack.com/start)
- **Roteamento**: [TanStack Router](https://tanstack.com/router)
- **Estilização**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Ícones**: [Lucide React](https://lucide.dev/)
- **Ferramenta de Build**: [Vite 8](https://vitejs.dev/)

---

## 💻 Como Rodar o Projeto

### Pré-requisitos
- Node.js >= 18
- npm ou bun

### Instalação e Execução

```bash
# Clone o repositório
git clone https://github.com/pedrobrasill/lionelmessi.git

# Entre no diretório
cd lionelmessi

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```
